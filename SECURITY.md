# Security policy

## Reporting vulnerabilities

Do not disclose security vulnerabilities, passwords, or sensitive data in public issues.
Repository maintainers must configure **GitHub private vulnerability reporting** or add
an approved private reporting contact before inviting outside contributors.

**Private reporting contact: NOT YET CONFIGURED.**

## Security expectations

- Keep credentials out of Git, screenshots, logs, and AI prompts.
- Enforce access control on the server/database layer, not only in the UI.
- Validate changes before production deployment; use least-privilege credentials.
- Rotate and revoke credentials if exposure is suspected.
